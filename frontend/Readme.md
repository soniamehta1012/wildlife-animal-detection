
# Wildlife Animal Detection – Frontend

## Overview

The frontend provides a simple and user-friendly interface for the Wildlife Animal Detection website.

Users can navigate through the website, upload animal images, view detection results, and check previous detection history.

---

## Website Flow


Home
  ↓
Upload Image
  ↓
Image Preview
  ↓
Detection Result
  ↓
Detection History


Pages::

1. Home Page

The home page introduces the Wildlife Animal Detection website and explains its main purpose.

It provides simple navigation and allows users to start the animal detection process.

2. Upload Image Page

This page allows users to select or upload an image of a wildlife animal.

The selected image will be displayed as a preview before proceeding with detection.

3. Detection Result Page

This page displays the result after an uploaded image has been analyzed.

It shows the detected animal along with its confidence score and the relevant result information.

4. Detection History Page

This page allows users to view their previous animal detection results.

It can display information such as the detected animal, confidence score, image, and detection date.
